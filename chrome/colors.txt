To change colors, replace the default values in both the userChrome.css and userContent.css files. For normal browsing colors, replace the variables under "NORMAL BROWSING COLORS" in both files. For private browsing window colors, replace the variables under "PRIVATE BROWSING COLORS" in userChrome.css.

*some colors are still controlled by themes. if things don't look right, check that you are using a theme that matches whatever css colors you are using (light for default, dark for dark, etc.)
